# ميزان المنطقة

واجهة الأخبار والبيانات منشورة كملفات مستقلة على Netlify، دون اتصال بخادم Sites القديم.

## النشر
اربط المستودع بمشروع mizan-news الموجود في Netlify. فرع النشر main، مجلد النشر site، وأمر البناء فارغ. ملفات الواجهة مبنية مسبقاً؛ تحديث الأخبار لا يحتاج تثبيت حزم أو مفاتيح إضافية.

## تحديث العدد
في commit واحد على main: أضف site/data/editions/<id>.json، وحدّث site/data/latest.json وsite/data/history.json. احتفظ بالأعداد السابقة والصور ومعلومات حقوقها. لا تعِد استخدام تاريخ القطع السابق لعدد جديد، ولا تكتب فوق عدد أحدث. بعد نشر Netlify تحقق من معرف العدد الجديد من /data/latest.json، ومن الأرشيف /data/history.json. نجاح commit وحده لا يثبت نجاح نشر Netlify.

## تعديل الواجهة
المصدر في src وpublic. شغّل npm install ثم npm run build، وانسخ dist إلى site. لا تضف node_modules أو بيانات دخول إلى Git.

## الحالة
العدد الحالي والأعداد السابقة نُقلت من الملفات المحفوظة للموقع. ربط GitHub بـNetlify لا ينشئ مهمة تحرير تلقائية. يجب تعديل مهمة الأخبار الموجودة لتكتب إلى هذا المستودع بعد التحقق التحريري، ثم التأكد من نشر العدد.
